# 姜来同学：GBIM 复现指南

作者来源与版本见团队根目录的 `UPSTREAM.md`。已展平作者目录，入口直接为 `methods/GBIM/main.py`；从这里运行，`data/` 和 `model_state/` 的相对路径保持有效。作者说明保留在 `readme.md`。

## 环境与数据

团队尚未验证安装和训练。在本目录建立独立 `.venv`，先检查 `requirements.txt`：旧 NumPy/SciPy 与 CUDA 版 `torch_sparse` 不能直接套到 Apple Silicon。安装后记录实际平台、Python、依赖版本与完整命令。

作者附带 LastFM 数据及初始训练样本。本机已保留；其他成员从团队根目录下载固定版本作者包并取出数据：

```bash
gbim_tmp=$(mktemp -d)
curl -fL https://codeload.github.com/zirui-yuan/GBIM/zip/d5bd89880dfd6d56275be7b485a19b50f461bba3 -o "$gbim_tmp/author.zip"
unzip -q "$gbim_tmp/author.zip" -d "$gbim_tmp"
mkdir -p methods/GBIM/data methods/GBIM/model_state/lastfm
cp -R "$gbim_tmp/GBIM-d5bd89880dfd6d56275be7b485a19b50f461bba3/GBIM/data/." methods/GBIM/data/
cd methods/GBIM
```

临时下载目录可在确认复制成功后自行删除。其他数据集从作者 `readme.md` 给出的 data.zip 链接获取并解压到当前 `data/`。数据与权重默认不提交 Git。

## 先完成原生复现

准备好环境、LastFM 数据和模型输出目录后，作者默认运行命令是：

```bash
python main.py
```

默认任务为 LastFM、Multi-IC、k=5。若改变传播模型或预算，需检查相应训练样本是否存在，缺少时先生成，并创建模型输出目录：

```bash
python datasample.py -d lastfm -dm IC -k 5
python main.py -d lastfm -dm IC -k 5
```

这些是作者入口的命令，尚未由团队验证跑通。保存优化过程、随机种子、运行时间和最终用户—信息种子对；小型结果放团队 `results/GBIM/`，英文报告放 `reports/GBIM/`，有成果时再建目录。本目录 `resultslog.txt` 是作者附带记录。

## 与 HIM、DeepSN 比较

GBIM 优化 (用户, 信息) 种子对，在用户网络与信息关联网络中做 Multi-IC/Multi-LT，目标与普通 IC 的唯一激活用户数不同。先复现原任务，后单独验证统一任务适配，再参与横向排名。

将信息数设成 1 并不能直接完成适配：作者候选生成会抽取 k 个不同信息，k>1 时无法这样采样；还需要检查信息编号 0 与“未选种子”编码冲突。
