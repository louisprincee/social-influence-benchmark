# 李同学：DeepSN 复现指南

作者源码与基准版本见团队根目录的 [README.md](../../README.md)。入口为 `model.py`。本机已在 Apple Silicon Mac Air、Python 3.11.17、CPU 上验证 Jazz 原生协议。

## 环境

不要套用 HIM 的依赖锁。本目录独立虚拟环境：

```bash
# 本机使用已有的 Python 3.11.17
/opt/anaconda3/envs/deepsn/bin/python -m venv methods/DeepSN/.venv
source methods/DeepSN/.venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r methods/DeepSN/requirements.txt
python -m pip check
```

Torch 必须是 **2.5.1**。2.14 的 Mac wheel 与 PyG 的 `torch-sparse` 扩展不匹配，导入会直接崩溃。已验证组合见 [results/DeepSN/environment.json](../../results/DeepSN/environment.json)。

## Ciao：与 HIM 对齐的三种子实验

刘同学提供的 MAT 哈希与 [data/ciao_source_manifest.json](../../data/ciao_source_manifest.json) 一致；共享图哈希与 [data/ciao_wic_protocol.json](../../data/ciao_wic_protocol.json) 一致。每个训练种子使用独立的 30 条合成 WIC 级联，预算 366，50+200 epoch，独立评估种子基数 1042、1000 轮。

```bash
python data/process_ciao.py
for s in 42 43 44; do
  python methods/DeepSN/prepare_ciao_sg.py --seed-rate 5 --pairs 30 --seed $s \
    --output methods/DeepSN/data/ciao_n30_s$s/ciao_mean_IC50.SG
  python methods/DeepSN/model.py -d ciao -dm IC -sp 5 --seed $s \
    --estimation_epochs 50 --score_epochs 200 --eval_rounds 0 \
    --data_dir methods/DeepSN/data/ciao_n30_s$s \
    --output results/DeepSN/ciao_IC_k5_n30_s$s.json
  python methods/DeepSN/evaluate_ciao_seeds.py \
    --result results/DeepSN/ciao_IC_k5_n30_s$s.json \
    --rounds 1000 --evaluation-seed 1042 \
    --output results/DeepSN/ciao_wic_independent_n30_s$s.json
done
```

三种子平均激活 **595.05**（样本标准差 20.30），覆盖率 **8.132%**，95% t 区间（df=2）为激活用户 [544.63, 645.47]。HIM-ASW 同协议三种子均值约 735.03 / 10.05%。两边图、概率、预算和评估流已对齐，但优化器不同，且 DeepSN 没有 HIM 的 100 轮在线验证；区间很宽，**不能写成算法排名**。汇总见 [results/DeepSN/ciao_wic_three_training_seeds_2026-10-26.json](../../results/DeepSN/ciao_wic_three_training_seeds_2026-10-26.json)。

更早的 16 对 / 单种子 / 100 轮评估只是管道结果，不要代替上述三种子数字。
