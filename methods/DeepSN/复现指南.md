# 李同学：DeepSN 复现指南

作者源码与基准版本、团队适配摘要见团队根目录的 [README.md](../../README.md)；作者 README 保留在本目录。入口为 `model.py`。

## 环境与数据

目前源码已准备，团队尚未验证安装和训练。请在本目录建立独立 `.venv`，按照实际导入梳理 PyTorch、图神经网络及 sheaf 模块的依赖，跑通后记录 Python、平台、完整安装命令和版本。不要套用 HIM 的环境锁定文件。

从团队根目录获取默认实验数据（刘同学本机已经有这些作者数据，无需重复下载）：

```bash
mkdir -p methods/DeepSN/data
curl -fL https://raw.githubusercontent.com/Aselahp/DeepSN/bbc7780e448baf2b7f5bdc08668748c10f286ca1/data/jazz_mean_SIS200.SG -o methods/DeepSN/data/jazz_mean_SIS200.SG
cd methods/DeepSN
```

其他 `.SG` 输入按作者仓库对应文件获取，或研究 `datagen.py`、`gen_data.py` 的生成流程。二进制数据在本机保留，默认不提交团队 Git。

## 先完成原生复现

1. 核对 `model.py` 的 `parse_args(args=[])`：当前会忽略终端参数，`python model.py -h` 也不能可靠显示帮助。改为读取实际命令行，再验证参数生效，直接提交代码修改。
2. 先使用作者小数据完成一轮运行。默认设置为 Jazz、SIS、20% 种子比例；显式记录实际传播模型和预算。
3. 核查训练/评估划分、节点映射、设备、随机种子；保存命令与日志，导出最终真实种子集合。
4. 小型结果放团队 `results/DeepSN/`，英文报告放 `reports/DeepSN/`，产生成果时再建目录。依赖版本和已验证的运行命令补充到本指南。

这里尚未提供团队验证通过的训练命令；仅下载数据不代表复现已经完成。

## 与 HIM 比较

作者 IC 使用 `1 / in_degree(target)` 的传播概率，LT 阈值在 [0.3, 0.6] 采样，均与现有 HIM 实验设置不同。按团队 README 共同对齐图、预算及独立评估；原生数值先分别记录。
