# 仓库结构与实验约定

更新时间：2026-10-09。目标 GitHub 仓库为 louisprincee/social-influence-benchmark，公开发布由用户自行操作。

## 目录为什么这样分

- **methods**：直接进入作者代码。HIM、DeepSN、GBIM 分别是固定版本的 Git 子模块，没有团队添加的内层包装。
- **reproduction**：各成员独立维护的环境、补丁和中文指南。避免把团队说明混入作者代码。
- **data**：三人共用的数据来源、处理规则和公共输入。
- **experiments**：共同实验配置、统一评估及结果。原论文复现与统一比较分别存 native 和 benchmark。
- **reports**：个人与小组的课程报告。个人英文综述仍按课程要求使用英文。
- **docs**：中文协作和方法接入说明。

空目录不需要多个 .gitkeep。Git 只追踪文件，现在通过各目录有实际内容的 README 或配置记录保留职责说明。

## 已有 HIM 工作如何保留

原独立 HIM 目录没有移动。其 data、configs、save、local_checks 已复制到 methods/HIM，73 个文件逐一核对哈希。新代码中的两个修正与原代码一致。已有环境没有搬动，reproduction/HIM/.venv 是本地软链接；它不进入 Git，其他电脑需单独安装环境。

已有模型权重、完整日志和缓存可直接在新方法目录使用。GitHub 保存小型结果、审计、哈希清单和环境版本，原始文件仍本地保留。迁移不会把原实验改成统一对比结果。

## 数据与任务的边界

已有邮件示例为 89 个用户、464 条有向边和 15 个孤立点；它尚未定为最终三方法数据。HIM 按无向结构学习，DeepSN 有 IC/LT/SIS 设置，GBIM 优化用户—信息种子对，因此需要明确记录适配条件。

DeepSN 的入口忽略命令行参数，默认 SIS，训练与评估划分也需要核对。GBIM 的候选生成抽取 k 个不同信息，不能把信息数直接设成 1 就宣称普通 IC 适配完成，还需检查编号 0 的编码问题。

各自先复现原问题。统一评估程序、新数据转换器及完整三方法对比尚未实现。后续新增功能要有真实输出、清楚的参数记录和可复查的评估。

## 课程材料

至少三种方法在新的有趣数据集上比较，不能仅以下载了三个仓库认定完成。Milestone 使用真实已完成内容；个人英文综述不少于1000词，至少10篇参考文献、近三年不少于5篇，与每名组员的参考文献交集不超过3篇。

HIM 当前综述副本保存在 reports/HIM，编辑器中的原源文件仍在原课程材料目录。修改报告时确认编辑哪一份，避免出现不同版本。
