# 统一评估协议

公共评估代码尚未实现。本目录先记录准入条件，防止把不同实验混在一起。

评估前核对图、节点编号、种子定义、预算、传播模型及概率或阈值。传入的种子必须合法、去重，并符合预算。HIM/DeepSN 的用户种子不能直接替代 GBIM 的用户—信息种子对。

最终评估与训练和调参分离，使用独立随机数；对可比方法尽量复用同一批传播样本。记录平均激活量、覆盖率、模拟标准差、Monte Carlo 标准误和置信区间，并与多次训练之间的变化分开。

当前可用的原生 HIM 评估仍在 methods/HIM 的作者实现中；详细调用方式见 reproduction/HIM/复现实验指南.md。其验证指标不表示本目录已经有统一评估器。
