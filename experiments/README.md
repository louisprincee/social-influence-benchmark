# 团队共享实验

这里集中存放实验配置、评估约定、执行脚本及结果。各自的模型环境与补丁放在 reproduction，各自的作者代码放在 methods。

| 子目录 | 用途 | 当前状态 |
|---|---|---|
| configs | 实验参数及配置说明 | 包含 HIM 已完成实验的参数记录；不是自动启动器 |
| evaluation | 独立评估规则与后续实现 | 中文协议已写，公共评估代码待实现 |
| scripts | 批量运行、结果导出脚本 | 入口与输出约定已写，公共脚本待实现 |
| results/native/HIM | HIM 作者协议结果 | 已核验；本机原始运行保存在 methods/HIM/save |
| results/benchmark | 统一协议比较结果 | 尚无结果，进入条件见其 README |

## 各自实验可以先开始

HIM 已有真实结果，刘同学继续自己的复现与敏感性分析。李同学、姜来同学分别按 reproduction/DeepSN 和 reproduction/GBIM 下的指南完成环境与小规模作者数据实验。

不同方法不用共享训练缓存格式，也不用安装到同一个环境。首次运行后各自创建 results/native/方法名/运行编号 目录，保存小型 JSON、种子集、参数和日志摘要。数据与权重另行本地保存。

## 汇总时必须一致

比较前共同确定：图及节点映射、方向、传播模型与参数、种子定义与整数预算、各方法可以使用的信息、独立评估随机流、重复次数及时间口径。

训练或调参使用的随机数与最终评估分开。最终评估尽量使用同一批传播随机样本，报告均值、标准差与估计误差；训练时间、选点时间、评估时间分别记录。

IC、SIS、Multi-IC 的原生数值不混成一张优劣排名。三种方法只有在任务对齐并重新评估后，才进入 results/benchmark。
