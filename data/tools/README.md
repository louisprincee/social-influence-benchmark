# 数据处理工具：职责与待办

本目录以后放团队共用的数据处理代码，当前尚无已实现的转换器。

输入来自 data/raw；公共图与节点映射写到 data/processed；来源和处理统计写到 data/manifests。各方法的专用输入通过适配器生成到作者所需的数据目录。

共同确认后再实现以下流程：

1. 固定原数据来源并计算 SHA-256。
2. 根据同一组窗口、过滤和去重规则生成图。
3. 生成稳定的内部节点编号，保留并说明孤立节点。
4. 分别导出 HIM、DeepSN、GBIM 的输入，并核对目标函数与传播语义。
5. 写出参数、统计和生成文件哈希，保证三人使用的是同一份公共数据。

HIM 目前保存的 Cora-ML 结果属于作者数据复现，不是该处理工具的输出。
